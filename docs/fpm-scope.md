# Scope of this repository

This is the home of FPM, a EuroLeague player impact metric. The aim here is to be open about how the
metric works while keeping the finished model itself private.

The line is simple. The methods, and the thinking behind them, are documented here, and the companion
docs explain them in plain terms. The exact scripts, the full set of features, and the tuned weights are
not published. You can follow how FPM is built and why each decision was made, but you will not find a
copy you can run end to end. That is on purpose: it keeps the project honest about its methodology while
leaving room to keep improving the model.

## Source and use

FPM is built from publicly available EuroLeague data, and that data is open here for anyone to use. If
you want to build your own impact model, test an idea, or just dig through the numbers, it is there for
exactly that, and whatever you make with it is your own. A mention or a link back is appreciated, and the
LICENSE file holds the formal terms.

## Updates

During the EuroLeague season this repository is kept current and refreshes as the season goes. Between
seasons it rests until the next one begins.
